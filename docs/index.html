Proyecto de extracción de datos y DevOps

Este proyecto continúa la primera evidencia de Programación para Análisis de Datos. Se trabaja con la información del libro A Light in the Attic, publicado en Books to Scrape.

Herramientas utilizadas

En la primera práctica se utilizaron BeautifulSoup, Selenium y Scrapy para obtener información del producto. En esta segunda parte se usa Git y GitHub para guardar los cambios y GitHub Actions para ejecutar revisiones y pruebas automáticas.

Pruebas automáticas

El flujo de trabajo revisa el estilo del código con Ruff y ejecuta pruebas con unittest. Estas pruebas comprueban funciones para limpiar valores y calcular la completitud de los datos.

Despliegue

Cuando los cambios llegan a la rama main y las pruebas terminan correctamente, GitHub Actions publica esta página mediante GitHub Pages.

Nota: Books to Scrape es una página de demostración. Los precios y las calificaciones se usan únicamente para practicar.
